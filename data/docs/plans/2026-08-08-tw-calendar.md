# 台湾证券市场 2025-2026 交易日历计划

日期：2026-08-08

状态：完成

## 目标

依据交易所官方资料生成 `data/tw_calendar.csv`，覆盖 2025、2026 两个完整年度。
文件无 header，每个证券市场交易日一行，固定为 `YYYYMMDD`，严格升序且不重复。

## 范围

- 日历定义为台湾证券市场 TWSE / TPEx 的普通交易日。
- 同时核对 TWSE 与 TPEx 官方年度开休市资料；若两者存在差异，停止生成并记录差异。
- 不表达 TAIFEX 夜盘交易日归属、半日交易时段或逐日开收盘时间。
- 不根据现有 raw 文件反推交易日；raw 只用于生成后的独立异常对照。

## 实施

1. 搜索并保存 2025、2026 年 TWSE / TPEx 官方开休市资料及其发布日期/版本。
2. 从完整公历日期构造候选工作日，再按官方休市日、补行交易日和特殊安排得到交易日集合。
3. 生成无 header 的 `data/tw_calendar.csv`。
4. 验证日期合法、年份范围、严格升序、无重复、无普通周末；特殊周末交易日必须有官方依据。
5. 与 `/data/tw/raw/stock` 的日期及本轮空 dump 日期交叉检查，只报告差异，不用 raw 修改官方日历。
6. 更新 `data/docs/onboarding.md`，记录日历 contract、事实源和下一步。

## 验证

- 独立按年份统计交易日数量、首末日期与休市日期。
- 从官方资料重新生成一份临时集合，与提交文件逐行比较。
- 检查所有已成功生成股票 CSV 的日期是否属于官方交易日，并列出例外。
- 运行 `git diff --check`，审阅完整 diff 后原子提交。

## 回滚

本轮只新增静态日历、计划并更新 data onboarding；回滚独立提交即可，不修改 raw、CSV 或
converter。

## 风险

- “台北交易所”可能特指 TPEx；本文件按台湾证券市场 TWSE / TPEx 共用交易日历定义，并以
  两家官方资料一致为发布条件。
- 2026 年官方资料可能发生临时修订；文档必须记录本次使用的官方页面和资料日期。

## 结果

- 已生成 `data/tw_calendar.csv`：2025、2026 各 243 个交易日，共 486 行。
- 已逐项核对 TWSE JSON 与 TPEx 年度 PDF；两市场的普通股票交易日一致。
- 已完成格式、公历有效性、范围、严格排序、唯一性、工作日、官方休市集合及独立重建
  一致性检查。
- raw / CSV 对照发现三个交易日缺少可用 v2 CSV，并发现休市日 `20260406` 存在非空
  行情 dump；这些异常记录在 `data/docs/tw_calendar.md`，均未用于改变官方日历。
