# 台湾证券市场交易日历

更新时间：2026-08-08

## Contract

`data/tw_calendar.csv` 是台湾证券市场普通股票交易系统的交易日集合，当前完整覆盖
2025、2026 两个公历年度。TWSE 与 TPEx 在这两个年度采用相同的普通股票交易日；本文件
不表达 TAIFEX 夜盘交易日归属，也不覆盖债券等采用不同开休市安排的交易系统。

- schema：单列、无 header，每行一个 `YYYYMMDD`。
- 字段：`trading_day`，按 `Asia/Taipei` 的公历日期解释，不是 timestamp。
- 主键：`trading_day`。
- 排序：严格升序，无重复。
- 生成规则：公历星期一至星期五，排除交易所公告的休市日及“市场无交易，仅办理结算
  交割作业”日期，并以事后发布的天然灾害等临时休市公告覆盖年度日程；这两个年度没有
  周末补行交易日。
- 更新规则：交易所临时停市或修订年度日程时，以最新官方公告更新文件，并重新记录来源
  与校验结果；不得根据 raw 文件是否存在反推交易日。

`data/tw_calendar.csv` 共 485 行，SHA-256 为
`3e604dd33ae98ec0e8bc3e1fb4a22a1910b6893ee5e5f8e689d36b714f7aa431`。已验证日期格式与
公历有效性、年度范围、严格升序、唯一性、周末排除，以及 TWSE / TPEx 官方休市集合一致。

与现有股票 raw / v2 CSV 做独立对照时发现：

- 官方交易日 `20250616` 当前没有 v2 CSV，原因是 format1 basic-info 冲突。
- 官方交易日 `20260624` 的唯一 archive 损坏；已从 953,080,320 bytes 连续前缀发布
  `09:00:00-09:31:57` 的 partial v2 CSV，包括 4,785,082 行 orderbook 和 40,968 行
  basic-info，不是完整交易日。
- 临时休市日 `20260710` 的 archive 解压后为空，符合实际休市状态，不是数据缺失。
- 官方休市日 `20260406` 的 `gz`、`xz` 两个源均含非空 dump；当前已生成 15,102 行
  orderbook，其中绝大部分消息是 basic-info/control，另有少量行情。官方资料明确当天是
  民族扫墓节补假，因此日历仍排除该日；该 raw 应作为休市日行情异常单独调查，不能视为
  正常交易日证据。
